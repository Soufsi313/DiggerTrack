# DiggerTrack

DiggerTrack est une application de recherche multiboutique permettant de suivre les prix de produits et d'être averti lorsqu'une offre ou une réduction correspond aux critères définis par l'utilisateur.

L'objectif est de permettre à l'utilisateur de surveiller ses produits favoris sur plusieurs boutiques sans devoir vérifier manuellement les prix.

## Fonctionnalités prévues

- Recherche de produits sur plusieurs boutiques.
- Ajout de produits aux favoris.
- Suivi des prix.
- Historique des prix.
- Définition d'un prix cible.
- Définition d'un pourcentage de réduction souhaité.
- Alertes lors d'une baisse de prix.
- Notifications Windows.
- Notifications par e-mail.
- Comparaison des prix entre plusieurs boutiques.

DiggerTrack pourra suivre différents types de produits, notamment :

- Jeux vidéo.
- Consoles.
- Composants informatiques.
- Vêtements.
- Accessoires.
- Autres produits disponibles sur les boutiques compatibles.

## Technologies

Le projet utilise actuellement :

- C#
- .NET 10
- .NET MAUI

## Plateformes

Le développement commence avec une application Windows.

Une compatibilité avec d'autres plateformes, notamment Android et iOS, pourra être ajoutée par la suite grâce à .NET MAUI.
